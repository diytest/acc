Accelerometer USB without a memory chip

operates only while connected to a computer's USB port; power is also supplied via USB. After each measurement the accelerometer sends the results to the computer.

In the photo (top view), between the USB connector (left) and the MEMS accelerometer chip (right) is the location for the memory chip - in this version it is absent.
A presentation of the accelerometer's operation: accelerometer.pps,

Accelerometer 16g USB and accelerometer 200g USB USB are made on identical boards; they differ only in the range of measured accelerations. All other parameters and the software are identical.

The included software lets you set the following measurement parameters:
- the range of measured accelerations

accelerometer 16g USB     ±2g,   ±4g,     ±8g or ±16g, 

accelerometer 200g USB ±25g, ±50g, ±100g or ±200g,

- the number of axes of the accelerometer along which measurement is performed (using fewer than all 3 axes is useful when recording data to non-volatile memory; when plotting a large number of samples - plotting a graph from data arrays several megabytes in size takes a noticeable amount of time, so if only, say, one axis is of interest, the plotting time can be reduced threefold),
- the sampling rate of the accelerometer: 3200 Hz, 1600 Hz, 800 Hz, 400 Hz, 200Hz, 100Hz, 50Hz, 25 Hz, 12.5Hz or 6.25 Hz
- the measurement time / number of samples, limited only by the amount of RAM in your computer.

The software lets you control the accelerometer, read the measurement results, display them as acceleration graphs, and save the resulting data as files.
The computer application that works with the accelerometer provides convenient functions:

  1. viewing graphs,
  2. signal processing (smoothing, spectrum and trend calculation),
  3. searching for files by their comments,
  4. documenting results: 
  • saving graph data or fragments of it in text (txt) format or csv format (for import into MS Excel),
  • copying to the clipboard for subsequent pasting into documents, e.g. MS Word, PowerPoint,
    • graphs (in wmf format, image quality is not lost when compressing/stretching)
    • comments for files with automatic addition of file information (name, recording time)
    • spectrum calculation results (value and frequency of the maximum spectral component, all spectral components in text format) and trend results (the formula describing the trend line)

Accelerometer USB with a 256KB non-volatile memory chip installed on the board

Accelerometer with memory can operate autonomously, powered from a voltage source of +4.75V to +10V. Current consumption is 12mA.
A presentation of the accelerometer in autonomous mode:  autonomous.pps
the accelerometer's operation in autonomous mode is also shown in a video

Selecting the mode  of the accelerometer is done via USB; the accelerometer is then disconnected from USB, and measurements can be performed at locations where installing a computer is not possible.

The photo on the left at the top of the page shows the board of the accelerometer with the 256KB memory chip installed - you can also purchase the accelerometer without it, and if needed, buy the memory and regulator chips and install them yourself.

The non-volatility of the accelerometer's memory means that storing data already written to memory does not require a power source; writing and reading data does require a power source.

Ways to start the accelerometer in autonomous mode

measurement can begin

- by a command sent via USB,
- by a PAUSE-START command: measurement will begin after an interval of time set by the operator; during the pause you can disconnect the device from the computer's USB and start the process whose parameters are being measured by the accelerometer. . When the process ends, the accelerometer is connected to the computer to transfer the recorded measurement results.
- by opening the contacts on the accelerometer:
board: for this, a command is sent via USB that initializes waiting for the opening of a pair of contacts on the board; after that the accelerometer can be disconnected from the computer. Now, when the contacts on the accelerometer board open, the accelerometer measurement will begin. An external device, for example, one with a photodetector that closes the contacts when a light beam hits a light-sensitive element, can be connected to the board.
Illustrated  information about the startup modes and about power connection can be found in the Help file, in the section "Writing to the accelerometer's memory chip"
(the Help file is in the archive acc-usb)

The included software lets you set the following measurement parameters:

- the range of measured accelerations

of the accelerometer 16g USB     ±2g, ±4g, ±8g or ±16g, 
accelerometer 200g USB ±25g, ±50g, ±100g or ±200g,

- the number of axes of the accelerometer along which measurement is performed (using fewer than all 3 axes is useful when recording data to non-volatile memory; when plotting a large number of samples - plotting a graph from data arrays several megabytes in size takes a noticeable amount of time, so if only, say, one axis is of interest, the plotting time can be reduced threefold),

- the sampling rate of the accelerometer: 3200 Hz, 1600 Hz, 800 Hz, 400 Hz, 200Hz, 100Hz, 50Hz, 25 Hz, 12.5Hz or 6.25 Hz

- the measurement time / number of samples when recording in autonomous mode is limited by the memory capacity of 256KB. The maximum recording time 
        Trecording, seconds  =  (256 * 1024 - 20) /  2  / Number_of_axes  /  Sampling_rate,    
256 *1024 - memory size in bytes, 20 bytes for storing measurement parameters;
/ 2 - two bytes store one sample;
Number_of_axes - from one to three (X, Y, Z): for example, if it is enough to record acceleration along only the X axis, the measurement time can be tripled.
Sampling_rate is chosen programmatically from the range listed above (3200Hz, 1600Hz, ..., 6.25Hz). It is chosen depending on how fast the signal changes that need to be captured. See more about this here: Sampling rate under impact loading .
When recording along all 3 axes at a sampling rate of 3200Hz, the maximum recording time is 13.6 seconds.

A USB accelerometer with memory can also send results directly to the computer without writing to the memory chip; in that case the number of samples/recording time is limited only by the computer's RAM 

- start by opening contacts connected to the accelerometer board (e.g. a button or relay) is available only when recording to memory.

Updating the USB accelerometer's software

When new features are added, it is possible to update the software of both the microcontroller installed on the USB accelerometer board and the computer application.

The archive acc-usb contains the latest demo version of the computer application - in the demo application you can view graphs and test the processing of signals recorded to files. Files for demonstrating the application are packed in the archive dataAcc-usb

How to update the computer application:
Users of USB accelerometers can request the latest working version of the application  by e-mail.
 
ATTENTION! Scales.scl - the calibration coefficients file for your accelerometer  - it is generated from the results of the accelerometer's calibration and is sent to you by e-mail together with the application when the accelerometer is delivered! Keep this file, and when extracting the update files from the archive, replace the file of the same name extracted from the archive with YOUR Scales.scl file, extracted from the archive.
ATTENTION! The application for the USB accelerometer is not suitable for controlling the accelerometer with an RS-485 interface
However, both applications have the same capabilities; the file format written by these applications is the same, so files from both types of accelerometers can be viewed and processed by either of these applications.

Microcontroller firmware updates:

Users of USB accelerometers can request updated firmware by e-mail

How to update the microcontroller firmware on the accelerometer board:
- download the updated firmware for the microcontroller (see the link to the latest update file *.blc below), and remember the folder into which you placed the update file
- download and unpack the archive BootAccClient , run the BootAccClient.exe application, and follow the instructions that appear on the screen as the application runs.
ATTENTION! It is easier to load the firmware into the microcontroller of the USB accelerometer board  USB accelerometer from the same computer that the accelerometer was previously used with, since loading the updated firmware into the microcontroller requires the USB accelerometer drivers!
