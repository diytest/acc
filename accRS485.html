for the 200g RS-485 accelerometer:  ±25g/±50g/±100g/±200g.

The accelerometer with the RS-485 interface  lets you place the measurement unit several dozen meters away from the computer; transmission of the DIGITAL data is carried out over a long 4-wire cable.

VIDEO Measurements with an RS-485 accelerometer

The accelerometers are built around a digital MEMS accelerometer chip from Analog Devices.

The remaining features of the accelerometer with the RS-485 interface are the same as those of the USB accelerometer without a memory chip (see the page USB accelerometer without a memory IC).

The 16g RS-485 accelerometer and the 200g RS-485 accelerometer are made on identical boards, differing only in their measured acceleration ranges. The remaining parameters and the software are identical.

The included software lets you set the following measurement parameters:
- the measured acceleration range

  of the 16g RS-485 accelerometer     ±2g,  ±4g,   ±8g    or ±16g, 

  of the 200g RS-485 accelerometer ±25g, ±50g, ±100g or ±200g,

- the number of accelerometer axes along which measurement is performed (using fewer than all axes matters when plotting a graph from a large number of samples - opening megabyte-sized files storing measurement results and plotting a graph from them takes a noticeable amount of time),
- the accelerometer's sampling rate 3200 Hz, 1600 Hz, 800 Hz, 400 Hz, 200Hz, 100Hz, 50Hz, 25 Hz, 12.5Hz or 6.25 Hz
- the measurement time / number of samples, limited only by the amount of RAM on your computer.

To get acquainted with the application's signal-processing, calculation, documentation, and data-export-to-other-applications capabilities, follow this link

The archive acc-usb contains an application for the USB accelerometer and a Help file; the archive dataAcc-usb contains data files recorded by both the USB accelerometer and the RS-485 accelerometer. 

The user interface of the applications for the USB and RS-485 accelerometers is no different (the difference is in internal commands, which isn't noticeable to the operator) - you can download it to get acquainted with how it works.
